# Welcome to BESA GmbH on GitHub 👋

We build software for EEG and MEG research and clinical applications. We’re glad you’re here!

Whether you’re looking for a helper script, want to automate a workflow, or are learning more about BESA, these links are a good place to start.

## Explore our public tools

### [BESA MATLAB Scripts](https://github.com/BESA-GmbH/BESA-MATLAB-Scripts)

Sample MATLAB functions for importing BESA files and working with data exported from BESA Research. You’ll find BESA2MATLAB, MATLAB2BESA, and additional utilities. The scripts are free to use; the repository README explains their scope and support details.

### [BESA Research Batches](https://github.com/BESA-GmbH/BESA-Research-Batches)

A collection of batch scripts to help process multiple files in BESA Research.

## Looking for answers?

- Browse the [BESA Wiki](https://wiki.besa.de/index.php?title=Main_Page) for help articles and practical guidance, or go straight to the [BESA Research Manual](https://wiki.besa.de/index.php?title=BESA_Research_Manual).
- Learn about [BESA products](https://www.besa.de/) and [BESA Research](https://www.besa.de/products/besa-research/besa-research-overview/).
- For product questions or support, visit the [BESA Support page](https://www.besa.de/support/support-page/).

If you have a question about one of the public repositories, check its README for the best way to get in touch.

Thanks for stopping by—we hope you find something useful!
